## 🛡️ Key Compliance Highlights for Reviewers

- **Target Audience:** Designed for young children (ages 3–5, 6–8, 9+) and families.
- **COPPA & GDPR-K:** Fully compliant. Zero personal data collected, stored, transmitted, or sold.
- **Google Play Families Policy:** Compliant. No third-party ad networks, no commercial tracking SDKs, no public social features.
- **Permissions:** No dangerous permissions (`CAMERA`, `RECORD_AUDIO`, `LOCATION`, `MANAGE_EXTERNAL_STORAGE`).
- **Data Storage:** All artwork, profiles, and color states reside exclusively within Android's sandboxed private app storage (`Context.getFilesDir()`).
- **Parental Controls:** Administrative actions (profile deletion, gallery wipe) require solving a mathematical parental challenge gate.

## 🚀 How to Enable GitHub Pages

To host this site live on GitHub Pages:

1. Push the contents of this repository to GitHub on branch `main`.
2. In your GitHub repository:
   - Go to **Settings** → **Pages**.
   - Under **Build and deployment**:
     - **Source**: `Deploy from a branch`
     - **Branch**: `main` / `/ (root)`
   - Click **Save**.
3. Within 1–2 minutes, GitHub will publish the site at:  
   `https://ntfsapps-tech.github.io/drawme-privacy-policy/`
